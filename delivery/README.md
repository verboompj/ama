# Workload Delivery Records

This directory holds operational artifacts for the Azure workload delivery team,
not explanatory guides or engineering-framework tests.

| Location | Purpose |
|---|---|
| [Delivery guide](../docs/delivery/README.md) | Seven roles, skills, prompt usage and workload scope |
| [Tasks](tasks.md) | Authorised-work prerequisites and initial workload backlog |
| [Templates](templates/) | Assignments, design/review/plan contracts and handoff records |
| [Work-package records](releases/README.md) | Artifact ownership, snapshots, evidence and loop ledgers |

Architecture, workload standards, validation guidance and collaboration rules live
under [`docs/delivery/`](../docs/delivery/). Native agent, skill and prompt definitions
remain under `.github/` for client discovery.

No package, infrastructure, pipeline or deployment is created by these definitions.
Start only the explicitly authorised workload task. Changes to the engineering-agent
setup require a separate maintenance request; they are not deployment-team deliverables.
