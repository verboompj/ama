# Workload Delivery Records

This directory holds operational artifacts for Azure workload delivery.

| Location | Purpose |
|---|---|
| [Delivery guide](../docs/delivery/README.md) | Nine roles, skills, prompt usage and workload scope |
| [Tasks](tasks.md) | Authorised-work prerequisites and initial workload backlog |
| [Templates](templates/) | Assignments, design/review/plan contracts and handoff records |
| [Work-package records](releases/README.md) | Artifact ownership, snapshots, evidence and loop ledgers |

Architecture, workload standards, validation guidance and collaboration rules live
under [`docs/delivery/`](../docs/delivery/). Native agent, skill and prompt definitions
remain under `.github/` for client discovery.

Start the explicitly authorised workload task using its accepted risk path.
Engineering-setup maintenance has its own user-authorised scope.
