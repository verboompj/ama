# Interactive Prototypes

Clickable drafts for exploring the case's user journeys. These are not production
applications or approved agency interfaces.

## Farmer Journey

The Field & File farmer demo covers applications, fields, evidence, case progress
and payments, with English and Hungarian language selection.

- [Prototype guide](farmer-journey/README.md)
- [HTML demo](farmer-journey/index.html)

Download and open the HTML file locally; no server or installation is needed.
It uses fictional data and does not connect to real sign-in, submission or payment
services.

The supporting [personas](../docs/Persona/personas-and-use-cases.md) and
[business-process flow](../docs/architecture/business-process-flow.md) remain in
`docs/`.
