# Sentinel Satellite Missions (Data Assets)

Sentinel satellites, operated by ESA/EUMETSAT for Copernicus, are the primary source of open Earth observation data.

| Mission | Sensor Type | Purpose |
|---|---|---|
| **Sentinel-1** | Radar (SAR), day/night, all-weather | Land and ocean monitoring; core input to the CAP Area Monitoring System |
| **Sentinel-2** | High-resolution multispectral optical | Land monitoring — vegetation, soil, water, inland/coastal areas; core input to CAP crop classification |
| **Sentinel-3** | Multi-instrument (altimetry, temperature, ocean/land colour) | Sea-surface topography, sea/land surface temperature, ocean forecasting, climate monitoring |
| **Sentinel-4** | Atmospheric spectrometer, geostationary (hosted on MTG satellites) | Air quality monitoring over Europe |
| **Sentinel-5** | Atmospheric spectrometer, hosted on MetOp-SG satellites | Global air quality data |
| **Sentinel-5P (Precursor)** | Atmospheric spectrometer | Trace gases and aerosols affecting air quality/climate; bridges gap before Sentinel-5 |
| **Sentinel-6** | Radar altimeter | Global sea surface height measurement for oceanography and climate |

Each mission (except 5P) is typically a constellation of ≥2 satellites for frequent, comprehensive coverage. Sentinel-1/2 refresh over a given parcel every 3–5 days — the basis of the CAP Area Monitoring System.
